🟦 Mission 1: Build a Binary Number (10 minutes)

Learn: Binary uses only 0 and 1. Each position has a value: 8, 4, 2, 1. Tap a bit to turn it ON (1) or OFF (0). Add the values that are ON.

Example: 0101 = 4 + 1 = 5 in denary.

🔄 Mission 2: Binary ↔ Denary (12 minutes)

How to convert binary to denary: Write 8, 4, 2, 1 above the four bits. Add the values where the bit is 1.
Example: 1010 = 8 + 2 = 10.
How to convert denary to binary: Choose the values 8, 4, 2, 1 that add up to your number. Write 1 for values used and 0 for values not used.
Example: 6 = 4 + 2 = 0110.

🔎 Mission 3: Hexadecimal Detective (10 minutes)

Learn: Hexadecimal uses 16 symbols: 0–9 and A–F. Each hexadecimal digit represents four binary bits. Use the chart below to help you.
A = 10B = 11C = 12D = 13E = 14F = 15

Example: Binary 1100 = 8 + 4 = 12 denary = C in hexadecimal.

🏆 Mission 4: Final Mixed Challenge (10 minutes)

Your mission: Solve three mixed conversions. You can use the 8–4–2–1 place values and the A–F chart. Check each answer and correct any mistakes.
Finish: When you have completed the questions, write one thing you learned and download your work.
